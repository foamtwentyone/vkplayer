## Ручной чек-лист (Windows 10/11 + Dota 2)

Подготовка: программа запущена, расширение установлено, во вкладке https://vk.com/audio играет плейлист.

### Связь и статусы
- [ ] Браузер закрыт → в окне «Браузер не подключён»; F10 → плашка «Браузер с расширением не подключён».
- [ ] Браузер открыт, VK не открыт → «Chrome: откройте vk.com»; F10 → «Вкладка VK не открыта».
- [ ] Открыта vk.com/feed без музыки → «плеер VK не найден» или «Подключено», но F10 → понятная ошибка, не «успех».
- [ ] Открыта VK Музыка, трек играет → «Подключено · Chrome», название и исполнитель совпадают с сайтом.
- [ ] Закрыть VkHotkeys и запустить снова → подключение восстанавливается само за ~2 с.
- [ ] Перезапустить браузер → подключение восстанавливается само.
- [ ] Chrome и Edge одновременно, музыка в Edge → управляется Edge.

### Горячие клавиши в Dota 2 (главное)
Для каждого режима Dota 2: «Окно без рамки», «Полноэкранный», «В окне».
- [ ] F10 — следующий трек; F9 — предыдущий; F8 — пауза/продолжить.
- [ ] В Dota 2 назначьте на F8/F9/F10 любые действия и убедитесь, что они **не** срабатывают при нажатии.
- [ ] Удержание F10 на 2 с переключает **ровно один** трек.
- [ ] Ctrl+Alt+↑/↓ — меняется громкость музыки, звук игры и системная громкость не меняются (микшер Windows).
- [ ] Удержание Ctrl+Alt+↑ — громкость плавно растёт.
- [ ] Ctrl+Alt+M — музыка выключена; повторно — вернулась прежняя громкость.
- [ ] Ctrl+Alt+Shift+→/← — перемотка ±10 с.
- [ ] Чат Dota 2: обычный набор текста не ломается.
- [ ] 30+ минут игры: клавиши продолжают работать (сторож хука).
- [ ] «Окно без рамки»: плашка видна поверх игры и не забирает фокус (камера/клики работают).

### Настройки
- [ ] Переназначить «Следующий трек» на Ctrl+PageDown → «Сохранить» → работает новая, F10 больше не перехватывается.
- [ ] Назначить одинаковую комбинацию двум действиям → обе подсвечены красным, «Сохранить» недоступна.
- [ ] Назначить «A» без модификаторов → ошибка; F12 → предупреждение про Steam.
- [ ] Пока поле ввода активно, F10 не переключает трек.
- [ ] Перезапуск программы → настройки сохранились.
- [ ] «По умолчанию» → «Сохранить» → вернулись F8/F9/F10.
- [ ] Режим «RegisterHotKey» → клавиши работают; комбинация, занятая другой программой, показана с ошибкой.

### Трей и автозапуск
- [ ] Крестик → окно скрыто, значок в трее, клавиши работают.
- [ ] ЛКМ по значку → окно; ПКМ → меню с управлением и «Выход».
- [ ] Повторный запуск VkHotkeys.exe → открывается уже запущенное окно, второй процесс не появляется.
- [ ] «Запускать вместе с Windows» → после перезагрузки программа в трее без окна.
- [ ] Подсказка значка трея показывает текущий трек.

### Ресурсы
- [ ] Диспетчер задач: VkHotkeys ~0 % CPU в простое и во время игры; VkHotkeys.Bridge — по одному на браузер.
- [ ] Программа работает без прав администратора.
