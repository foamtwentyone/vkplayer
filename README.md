# VK Hotkeys

Утилита для Windows 10/11: управляет музыкой **ВКонтакте в браузере** глобальными горячими клавишами — прямо
во время игры в Dota 2, без сворачивания игры и переключения окон.

| Действие | Клавиша по умолчанию |
|---|---|
| Пауза / воспроизведение | **F8** |
| Предыдущий трек | **F9** |
| Следующий трек | **F10** |
| Громкость + / − | Ctrl + Alt + ↑ / ↓ |
| Mute / вернуть прежнюю громкость | Ctrl + Alt + M |
| Перемотка вперёд / назад | Ctrl + Alt + Shift + → / ← |

Все клавиши настраиваются, есть проверка конфликтов, настройки сохраняются после перезапуска.
Громкость меняется **только у плеера VK**: системная громкость и звук Dota 2 не меняются.

## Как это работает

```
 Dota 2 (активное окно)
     │  F10
     ▼
┌───────────────────────────── VkHotkeys.exe (WPF, трей) ─────────────────────────────┐
│ Низкоуровневый хук клавиатуры (отдельный поток) ──► PlayerController ──► PipeServer │
│ «проглатывает» F10: игра нажатия не получает        ожидает подтверждение            │
└──────────────────────────────────────────────────────────────────┬──────────────────┘
                                         именованный канал (только текущий пользователь)
┌──────────────────────── VkHotkeys.Bridge.exe ───────────────────┴──┐
│ хост Native Messaging; браузер запускает его сам; пересылает кадры │
└──────────────────────────────────────────────────────────────┬─────┘
                                                stdin/stdout (Native Messaging)
┌──────────────── Расширение Chrome/Edge (Manifest V3) ───────┴──────────────────────┐
│ background.js — держит связь, выбирает вкладку VK (играющую), пересылает команды  │
│ content.js    — посредник между вкладкой и background                              │
│ page.js       — внутри страницы vk.com: Media Session API → window.ap → <audio>    │
└────────────────────────────────────────────────────────────────────────────────────┘
```

* **Горячие клавиши.** По умолчанию используется `WH_KEYBOARD_LL`: хук вызывается раньше, чем нажатие попадёт
  в любое окно или в Raw Input, поэтому Dota 2 не видит F8/F9/F10. Хук работает в отдельном потоке
  с повышенным приоритетом, обработчик ничего не ждёт (Windows снимает «медленные» хуки), а сторож
  каждые 30 с переустанавливает хук. Удержание F10 не пролистывает плейлист; удержание Ctrl+Alt+↑ плавно
  повышает громкость. Альтернативный режим — классический `RegisterHotKey` (переключается в настройках).
* **Управление VK.** Расширение использует интерфейсы самой страницы, без кликов мышью и без
  переключения окон:
  1. обработчики **Media Session API**, которые VK регистрирует для мультимедийных клавиш клавиатуры
     (следующий/предыдущий трек, play/pause, перемотка) — самый стабильный способ;
  2. внутренний объект плеера VK **`window.ap`** (`playNext`, `playPrev`, `setVolume`, `getCurrentAudio`…);
  3. элемент **`<audio>`**, через который идёт звук (громкость и перемотка, если первые два способа недоступны);
  4. кнопки плеера в DOM (`element.click()`) — последний запасной вариант.

  Каждая команда **проверяется**: успех возвращается только если трек действительно сменился, пауза
  действительно поставилась и т. д. Если VK изменит сайт и плеер не найдётся, приложение покажет
  «Плеер VK не найден», а не ложный успех.
* **Громкость** — это громкость плеера VK (та же, что ползунок на сайте), а не системная.
  Mute запоминает текущий уровень и восстанавливает его повторным нажатием (или нажатием «Громкость +»).
* **Связь.** Мост — маленький консольный процесс, который браузер запускает сам при старте расширения.
  Если приложение ещё не запущено, мост ждёт и подключается, как только оно появится; при закрытии
  браузера мост завершается. Несколько браузеров одновременно поддерживаются — управляется тот, где играет музыка.

Подробности протокола: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

### 1. Получить программу

**Вариант А — собрать самому** (нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)):

```bash
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
```

Готовая папка появится в `dist\VkHotkeys`. Если на компьютере, где будет работать программа, нет
.NET 10 Desktop Runtime, соберите автономную версию:

```bash
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1 -SelfContained
```

**Вариант Б — артефакт CI**: вкладка *Actions* репозитория → последний запуск → артефакт `VkHotkeys`.

Скопируйте папку `VkHotkeys` в постоянное место, например `%LOCALAPPDATA%\Programs\VkHotkeys`.
Права администратора не нужны: программа пишет только в `HKEY_CURRENT_USER` и `%APPDATA%`.

### 2. Запустить программу

Запустите `VkHotkeys.exe`. При каждом запуске программа сама регистрирует мост Native Messaging
для Chrome, Edge, Brave, Vivaldi, Opera и Яндекс Браузера (внизу справа в окне будет
«Мост зарегистрирован…»). Если вы перенесли папку — просто запустите программу снова.

### 3. Установить расширение

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `VkHotkeys\extension`
   (в программе есть ссылка «Открыть папку расширения»).
4. ID расширения должен быть `jpmdbkdhjihibaiicamanjichgkpgila` — он задан ключом в `manifest.json`
   и одинаков во всех браузерах, мост разрешает подключение только ему.

> Не удаляйте папку `extension` после установки: распакованное расширение загружается браузером из неё.

### 4. Проверить

1. Откройте https://vk.com/audio и включите любой трек.
2. В окне программы статус станет **«Подключено · Chrome»**, появится название трека.
3. Нажмите F10 в любом окне — трек переключится, в правом верхнем углу появится плашка.

## Использование

* Программа живёт в **системном трее**. Крестик и «Свернуть» прячут окно, музыка управляется дальше.
  Выход — правой кнопкой по значку → «Выход».
* **Параметры**: автозапуск с Windows (запуск сразу в трей), закрытие в трей, уведомления о смене трека,
  автооткрытие VK Музыки, шаг громкости (1–25 %) и перемотки (1–60 с).
* **Уведомления**: «Плашка поверх игры» — своё окно, которое не забирает фокус и не мешает кликам;
  «Windows» — системные уведомления (в полноэкранных играх Windows их обычно скрывает); «Выкл».
  Ошибки («VK не открыт», «Плеер не найден») показываются при любом режиме, кроме «Выкл».
* **Изменение клавиши**: кликните по полю, нажмите нужную комбинацию. `Backspace` — убрать,
  `Esc` — отменить. Пока поле активно, глобальные клавиши отключены. Затем нажмите **«Сохранить»**.
  Конфликты подсвечиваются: дубликаты и системные сочетания (Ctrl+Alt+Del, Alt+F4…) блокируют сохранение;
  клавиши, занятые другими программами, F12 (скриншот Steam) и т. п. — предупреждение.
* Значок расширения в браузере показывает состояние связи и тоже умеет переключать треки.

Файлы программы:

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\VkHotkeys\settings.json` (читаемый JSON) |
| Журнал | `%LOCALAPPDATA%\VkHotkeys\log.txt` |
| Манифест моста | `%LOCALAPPDATA%\VkHotkeys\com.vkhotkeys.bridge.json` |
| Автозапуск | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `VK Hotkeys` |

### Удаление

```bash
VkHotkeys.exe --unregister
```

Команда удаляет регистрацию моста и автозапуск. Затем удалите расширение в браузере и папку программы
(и при желании `%APPDATA%\VkHotkeys`).

## Решение проблем

| Симптом | Что сделать |
|---|---|
| «Браузер не подключён» | Расширение не установлено или выключено; браузер закрыт. Во всплывающем окне расширения нажмите «Переподключить». |
| В расширении «Мост не зарегистрирован» | Запустите `VkHotkeys.exe` хотя бы раз, затем «Переподключить» в расширении. |
| «Откройте vk.com» | Нет открытой вкладки VK. Вкладку можно не держать активной — подойдёт фоновая. |
| «Плеер VK не найден» | Откройте раздел «Музыка» и запустите трек. Если не помогло — обновите вкладку (F5). |
| «Браузер запретил автозапуск» | После перезагрузки страницы браузер требует хотя бы один клик по странице VK. |
| Клавиши не работают в игре | Если Dota 2 (или Steam) запущены **от имени администратора**, Windows не передаёт их нажатия программам без прав администратора. Запустите Dota без прав администратора (по умолчанию так и есть) или VkHotkeys от имени администратора. |
| Плашка не видна в игре | В режиме «Полноэкранный» (exclusive fullscreen) окна поверх игры могут не отображаться. Выберите в Dota 2 режим «Окно без рамки». Сами команды выполняются в любом режиме. |
| Нужна диагностика | «Журнал» в окне программы; для расширения — `chrome://extensions` → «Service worker» → консоль. |

## Ограничения (честно)

* **VK не предоставляет публичного API управления веб-плеером.** Расширение опирается на Media Session API
  (стандарт браузера, его VK использует для мультимедийных клавиш) и на внутренний объект `window.ap`.
  Если VK изменит сайт, может перестать работать один из способов; расширение автоматически попробует
  следующий, а если не сработает ни один — честно сообщит «Плеер не найден» или «Плеер не отреагировал».
  Селекторы и порядок стратегий собраны в начале `extension/page.js`.
* Если расширение установлено, когда VK уже открыт, оно подключится к вкладке автоматически, но обработчики
  Media Session, зарегистрированные VK до этого, перехватить нельзя — будет использован `window.ap`/`<audio>`.
  Достаточно один раз обновить вкладку.
* **Античит.** Программа не взаимодействует с процессом игры: не читает и не меняет его память, ничего
  в него не внедряет. Глобальный хук клавиатуры — тот же стандартный механизм Windows, что используют
  Discord (push-to-talk), OBS и т. п.
* **Firefox** не поддерживается: в нём другой формат расширений и регистрации Native Messaging.
  Поддерживаются Chromium-браузеры: Chrome, Edge, Brave, Vivaldi, Opera, Яндекс Браузер.
* Обходов авторизации, DRM и защит VK нет и не будет: используются только интерфейсы страницы.
* Расширение распространяется как «распакованное» (режим разработчика). Для публикации в Chrome Web Store
  нужен аккаунт разработчика; при упаковке с другим ключом добавьте новый ID в `extraExtensionIds`
  в `settings.json`.

## Тестирование

Автоматические тесты (запускаются на Windows, Linux и в CI):

```bash
dotnet test tests/VkHotkeys.Core.Tests
```

49 тестов: разбор и конфликты комбинаций, логика перехвата (F10 проглатывается вместе с отпусканием,
удержание F10 не пролистывает треки, удержание громкости повторяется), настройки (сохранение, повреждённый
файл, нормализация), контроллер (нет браузера / нет вкладки / таймаут → ошибка, шаг громкости при быстрых
нажатиях, Mute с восстановлением, выбор играющего браузера) и **интеграция с настоящим процессом моста**.

Сквозной тест всей цепочки в настоящем Chromium с расширением и имитацией плеера VK
(три варианта: Media Session + `ap`, только `ap`, только Media Session):

```bash
dotnet build src/VkHotkeys.Bridge
dotnet build tests/e2e/harness
npm install --no-save playwright
npx playwright install chromium
node tests/e2e/run-e2e.js
```

Ручной чек-лист для Windows + Dota 2: [docs/TESTING.md](docs/TESTING.md).

## Структура проекта

```
src/
  VkHotkeys.Core/      логика без WinAPI: протокол, комбинации и конфликты, настройки, контроллер плеера, канал
  VkHotkeys.Bridge/    хост Native Messaging (консольный, ~100 КБ)
  VkHotkeys.App/       WPF-приложение: хук клавиатуры, RegisterHotKey, трей, плашка, автозапуск, окно
extension/             расширение Chrome/Edge (Manifest V3)
tests/
  VkHotkeys.Core.Tests/  модульные и интеграционные тесты (xUnit)
  e2e/                   сквозной тест в Chromium (Playwright)
scripts/               сборка дистрибутива, генерация иконок
docs/                  архитектура и чек-лист ручного тестирования
```
